06 / How to explain this project

Logic gate simulation: The application calculates the expected output using the selected Boolean logic function.

Fault injection: A software switch forces the simulated gate output permanently to logic 0 or logic 1.

Fault detection: The program compares the expected output with the simulated actual output for each input combination. A mismatch identifies a test that exposes the injected fault.

Important limitation: This version models faults at the gate output. It does not detect real electrical faults or automatically identify arbitrary physical component failures.
